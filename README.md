# Atmos – Weather Intelligence Dashboard

Atmos is a modern, responsive Weather Intelligence Dashboard designed to transform real-time weather data into meaningful, accessible, and actionable insights. Built using HTML5, CSS3, and JavaScript, the application provides users with a comprehensive view of current weather conditions, upcoming forecasts, atmospheric measurements, and environmental information through a clean and intuitive interface.

The project integrates live weather data from the Open-Meteo API to deliver location-based weather information without requiring a traditional backend server. Users can search for cities, explore weather conditions, monitor air quality, and access forecast information through an interactive dashboard.

## Key Features

- **Real-Time Weather Information:** Displays current temperature, weather conditions, and essential meteorological details for selected locations.
- **City Search:** Allows users to search for cities and retrieve location-specific weather information.
- **Geolocation Support:** Provides weather information based on the user's current location, subject to browser location permissions.
- **Hourly Forecast:** Presents upcoming hourly weather conditions to help users understand short-term changes.
- **7-Day Weather Forecast:** Displays extended weather predictions for planning daily activities.
- **Air Quality Monitoring:** Provides air quality information and environmental indicators.
- **Atmospheric Insights:** Displays important weather measurements, including humidity, wind speed, atmospheric pressure, and visibility.
- **Sunrise and Sunset Information:** Displays daily sunrise and sunset timings.
- **Temperature Unit Conversion:** Supports switching between Celsius and Fahrenheit.
- **Interactive User Interface:** Provides a visually engaging dashboard with dynamic weather information.
- **Light and Dark Themes:** Allows users to switch between different viewing modes.
- **Weather-Based Recommendations:** Provides contextual suggestions based on weather conditions.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screen sizes.

## Technology Stack

- **HTML5:** Structures the dashboard and its content.
- **CSS3:** Handles responsive layouts, styling, animations, and visual presentation.
- **JavaScript (ES6+):** Implements application logic, API integration, dynamic rendering, and user interactions.
- **Open-Meteo API:** Supplies weather forecast and related meteorological data.
- **Geolocation API:** Supports location-based weather searches.

## Application Architecture

Atmos follows a lightweight client-side architecture. JavaScript handles user interactions, communicates with external weather services, processes API responses, and dynamically updates the interface. CSS provides responsive styling, while HTML defines the application structure.

The application does not require a dedicated application server or database for its current functionality.

## Getting Started

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Allow location access if you want weather information based on your current location.
5. Search for a city and explore the dashboard.

An active internet connection is required to retrieve live weather information from external APIs.
